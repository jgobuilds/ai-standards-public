# ai-standards

Shared engineering standards, review lenses, and skills for AI coding agents.
Vendor-neutral: works with Claude Code, Cursor, Copilot, Codex, Gemini CLI, and
anything else that reads `AGENTS.md`.

**Start with [`AGENTS.md`](AGENTS.md)** — it is the source of truth, and the
worked example of the pattern this repo exists to spread.

Supersedes `org-standard` and `claude-skills`, which are consolidated here.
